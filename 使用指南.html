VIDEOCATCH / 快速开始

把正在看的视频，留在本地。

首次安装浏览器扩展大约需要一分钟。桌面程序与扩展连接后，你可以选择监听哪些标签页，再挑选要保存的视频。

0.5.0 · Windows / macOS 本地录屏与截图

Windows 10 / 11 x64 与 macOS 14+ 的程序包见 0.5.0 发布说明与下载。Apple Silicon 选择 arm64，Intel 选择 x86_64，以发布页实际提供的包为准。浏览器扩展继续沿用 0.4.2，录屏不需要扩展。旧版及本地开发历史见 版本记录。

macOS 首次打开

完整解压并保留 VideoCatch 文件夹，双击 VideoCatch.app。VideoCatchAI、文档和 extension 必须留在 .app 旁边，不能只移动 .app。

本包没有 Developer ID 签名或 Apple 公证。首次被系统阻止时先核实下载来源，再按「系统设置 → 隐私与安全性」提示允许打开。录屏、摄像头和麦克风需分别按系统提示授权。macOS 权限交互和实际硬件采集尚未人工验收；自动构建和合成媒体检查不代表已完成实机录屏、收音验证。

录下屏幕、声音或摄像头

  1. 在主窗口选择保存目录，点击顶部 录屏 / 截图。
  2. 选择全屏、区域、窗口或仅摄像头。区域先框选，拖动后松开，Esc 取消。Windows 全屏包含整个虚拟桌面，窗口模式采集客户区；Mac 全屏只录主显示器，区域和窗口须完整位于同一显示器。Mac 窗口模式裁剪屏幕矩形，遮挡内容会入镜，窗口移动或调整大小后会停止并保存。目标须保持可见且未最小化。
  3. 声音默认关闭，可选系统声音、麦克风或两者混合；连接新设备后点「刷新设备」。Windows 系统声音使用回环采集；Mac 系统声音需要已有且路由已配置的 BlackHole、Loopback 等虚拟回环输入，并手动选择，程序不安装驱动或修改声音输出。屏幕类录制可勾选右下角摄像头画中画。
  4. 选择画质、帧率、定时秒数（0 不限时）和倒计时。可开启鼠标指针，默认勾选「录制时最小化主窗口」，然后点「开始录制」。
  5. 浮动工具条可暂停、继续及停止并保存。暂停部分不进入视频。停止后必须等任务变为「已保存」并显示路径，MP4 才完成。

点击「截取图片」按当前全屏、区域或窗口范围保存 PNG；不需要音频或摄像头设备，也不支持仅摄像头截图。截图结束后面板恢复。文件使用唯一名称，不覆盖已有输出。

画笔与快捷键

「屏幕批注 / 画笔」可选颜色与粗细，支持撤销和清空。「结束绘制」或 Esc 保留笔迹并恢复桌面操作，「继续绘制」添加笔迹，「退出标注」移除覆盖层。标注仅进入全屏 / 区域录制与截图；窗口或摄像头录制、窗口截图前需退出标注。

先在录制面板选好范围，再勾选「启用全局快捷键」：
Ctrl + Alt + F9 开始 / 停止并保存
Ctrl + Alt + F10 暂停 / 继续
Ctrl + Alt + F11 截图
Ctrl + Alt + F12 打开 / 退出画笔

Mac 上 Alt 对应 Option，部分键盘还需按 Fn。快捷键被占用时会提示。浮动工具条会尽量排除在采集画面外，效果取决于平台支持。

一键开启 AI 协作

点击「开启协作并复制」，自动配对并复制带真实调用路径的指引，粘贴给能在同一台电脑执行命令的 AI。Windows 使用 PowerShell，Mac 使用 zsh/bash；Mac 终端在程序目录可执行 ./VideoCatchAI capabilities、./VideoCatchAI state，不能照抄 Windows 的 .exe 命令。

可控制采集来源查询、录制启停、暂停继续、PNG 截图、下载与裁剪；仅按明确需求开启屏幕、声音和摄像头。请求受理不代表保存完成，AI 需查询最终状态与文件路径。Mac 配对设置位于 ~/Library/Application Support/VideoCatch/ai-client.json，不要分享该文件。完整 JSON 调用示例见 AI 接口使用说明。扩展继续兼容 0.4.2，加载后请保留在固定位置。

01  扩展单独放好，再导入浏览器

  1. 把独立扩展包解压到固定位置，例如桌面 拾影浏览器扩展。导入后不要移动或删除该文件夹。
  2. 地址栏输入 edge://extensions；Chrome 使用 chrome://extensions。
  3. 开启「开发人员模式」，点「加载解压缩的扩展」，选中直接包含 manifest.json 的文件夹，不要选 ZIP 或上一层。
  4. 更新时覆盖原固定目录的文件，然后在扩展管理页点「重新加载」，检查版本为 0.4.2。更换目录则移除旧扩展后重新加载，避免安装两份。

02  连接 → 开始监听 → 回网页播放

  1. 打开桌面程序，点「复制配对码」。
  2. 点浏览器工具栏里的拾影图标，粘贴配对码，点「连接 / 刷新标签页」。
  3. 回桌面程序，单击左侧视频页面，再点「开始监听」。只选中一行不会开始监听；出现 ☑ 表示已监听。
  4. 回网页刷新并开始播放。后台标签页也可以，前提是仍在加载媒体。

顶部会提示下一步。停止时选中页面再点「停止监听」。桌面程序重启后需要重新配对。

03  选中右侧视频，保存

单击右侧发现的视频，设置保存目录，再点「保存所选视频」。Ctrl / Shift 可以多选。完成后点「打开文件夹」。

B站：刷新并播放后，优先等条目变成「B站音画合并」再保存。

YouTube：也可直接粘贴网页链接。浏览器能播放但下载超时，点击「检测本机代理」，成功后重新保存；或填写自己已有的本机代理地址。此选项不会修改系统网络设置，也不提供代理节点。

没有发现直链时，可点「直接添加所选页面」。其他软件复制的视频直链或受支持的网站分享链接，可以粘贴到「其他来源」。

04  裁剪片段与 AI 控制

点击「裁剪本地视频」，选择源文件并输入起止时间。新片段另存为 H.264/AAC MP4，不覆盖原片。点击「开启协作并复制」，粘贴给能在同一台电脑执行命令的 AI，即可让它控制监听、下载、查询、取消和裁剪；重启拾影后再点一次即可；具体命令见 AI 接口使用说明。此接口只在本机开放，不需要填写模型服务商密钥。

桌面重启后需要重新配对。普通文件直接下载，HLS/DASH 分段合并，不主动转码。当前版本不支持任意桌面软件的加密流量捕获，也不支持 DRM 绕过；登录验证、临时链接或网站限制可能导致下载失败。取消直播不保证生成可播放的最终文件。

发现不到：检查扩展是否连接、标签页是否已开始监听，然后刷新页面。列表未同步时，在扩展中点击连接按钮。完整功能范围见同目录 README.md。
